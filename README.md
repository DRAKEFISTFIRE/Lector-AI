# LectorIA

Plataforma educativa con Vue 3 + Laravel + Gemini.

## Estructura

- `frontend/`: aplicación Vue 3 + Vite
- `backend/`: API Laravel
- IA: Gemini
- Arquitectura preparada para cursos, documentos, quizzes, exámenes, flashcards, planes de estudio y modo Kahoot.

## Inicio

El proyecto contiene la estructura inicial de carpetas. Los proyectos Vue/Laravel pueden inicializarse dentro de sus respectivas carpetas con Vite y Laravel.
